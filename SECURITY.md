# Security Policy

## Supported versions

This is a demo. We fix security problems on the `main` branch only. Please check that the
problem still happens on the latest `main` before you report it.

Problems in the SDK itself belong to
[behavioralsignals-python](https://github.com/BehavioralSignalTechnologies/behavioralsignals-python/blob/main/SECURITY.md).

## Reporting a vulnerability

Please do not report security problems in public GitHub issues.

Email both of these addresses:

- lefteris@behavioralsignals.com
- dimitris@behavioralsignals.com

Please include:

- what the problem is and how it could be misused
- steps or code to reproduce it

Do not send real API keys or customer data.

We will reply to confirm we got your report and keep you updated until it is fixed.
